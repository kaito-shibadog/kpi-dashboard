# data/ — データ層

エージェントが実際に読む/加工するデータの置き場所。

## ⚠️ 機密の扱い（最重要）

- **`data/private/` … GitHubに絶対に上がりません**（`.gitignore` で遮断済み）。
  生の財務数値・顧客データ・個人情報はすべてここに入れる。
- `*.xlsx` `*.csv` `*.pdf` などの実データ拡張子も既定で追跡対象外。
- GitHubに上げてよいのは「構造の説明」「ダミー/サンプルデータ」だけ。

## 推奨の使い分け

| 置き場所 | 何を置くか |
|---|---|
| `data/private/`（非公開） | 実データ本体（MF会計エクスポート、業績管理表の実物 等） |
| `data/samples/`（追跡可） | 列構成を説明するためのダミーデータ |
| Google Drive / Notion | そもそも「読む・書く」だけの生資料（役会資料・議事録など） |

## メモ

迷ったら「これは金額の実数を含むか？」で判断。含むなら `data/private/` か Drive へ。
