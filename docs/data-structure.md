# KPI ダッシュボード - データ定義書

## スプレッドシート構造

### 1. 実績+見込PL
- **範囲**: A2:P104
- **用途**: 実績と見込みの PL データ
- **主要行**:
  - 行29: 売上高合計
  - 行55: 売上原価合計
  - 行56: 売上総利益
  - 行62: 人件費合計
  - 行89: 営業利益
  - 行92: 営業利益(本社費用割賦後)

### 2. 修正後予算PL
- **範囲**: A2:P104
- **用途**: 予算データ
- **主要行**:
  - 行29: 売上高合計
  - 行55: 売上原価合計
  - 行56: 売上総利益
  - 行62: 人件費合計
  - 行89: 営業利益
  - 行92: 営業利益(本社費用割賦後)

### 3. 実績+見込CF
- **範囲**: A1:O42
- **用途**: キャッシュフロー データ
- **主要行**:
  - 行11: 営業活動によるキャッシュフロー
  - 行22: 投資活動によるキャッシュフロー
  - 行29: 財務活動によるキャッシュフロー
  - 行33: 現預金残高

### 4. 【経営管理表IP】 PL：直接雇用
- **範囲**: A2:P92
- **用途**: 直接雇用セグメントの PL

### 5. 【経営管理表IP】 PL：派遣
- **範囲**: A2:P92
- **用途**: 派遣セグメントの PL

### 6. 事業指標サマリ
- **範囲**: B3:N19 (複数セクション)
- **用途**: 業種別データ、昨年比較

### 7. 【Hubspot IP】CRM一覧(金額)
- **範囲**: B1:O1000
- **用途**: パイプラインデータ（金額）

### 8. 【Hubspot IP】CRM一覧(見込み人数)
- **範囲**: B1:O1000
- **用途**: パイプラインデータ（見込み人数）

## 月別列マッピング（確定版）

### PL系シート（実績+見込PL, 修正後予算PL, 直接雇用PL, 派遣PL）
- 列A: 項目名
- 列C-M: 月別データ（11月〜10月）
- 列B: （不明）

### CF系シート（実績+見込CF）
- 列A: 項目名
- 列B-M: 月別データ（11月〜10月）

### 事業指標サマリ
- 列B: 業種/項目ラベル
- 列C-M: 月別データ（11月〜10月）

## 注釈

- GAS の extractPLSheet / extractCFSheet は、実際の列マッピングに合わせて修正が必要
- 前の実装での「列B-M」「normalizeMonthLabel」は PL/CF の列マッピングが異なるため、修正必須
