# docs/ — セマンティック層②の定義

ここは「源泉データ①」と「エージェント④」の間をつなぐ**意味の定義**を置く場所です。

現状のダッシュボードは「源泉データ①」と「エージェント④」が**行番号で直結**していて、
間の②セマンティック層・③ドライバーモデルが存在しません。
ここを言語化して積み上げることが、そのまま**複利資産の構築**になります。

## 置くもの

| ファイル | 内容 |
|---|---|
| `semantic-layer.md` | ②セマンティック層。4セグメントの境界定義、(X)/(Y)の判定基準（課金単位）、科目マッピング |
| `value-driver-tree.md` | ③ドライバーモデル。KPI→企業価値の接続ツリー。最重要ドライバーと各エージェントの担当ノード |
| `agent-roster.md` | ④エージェント群の全社スペック（Pass 1の契約） |
| （今後）`allocation-rules.md` | 本社費/開発費の割賦ルール（未決論点） |

## 使い方

エージェントの定義書（`.claude/agents/`）から、必要に応じてここの定義を参照させます。
「定義はここ、実行は部下」という分離を保つのがコツです。
