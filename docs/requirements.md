# KPI ダッシュボード - 要件定義

## 完成系：表示する項目リスト

### 会計タブ
1. **PL月次推移** (グラフ + テーブル)
   - グラフ：実績 vs 予算の月次推移
   - テーブル：詳細数字

2. **CF推移およびバーンレート&ランウェイ** (グラフ + テーブル)
   - グラフ：現預金残高の推移、バーンレート、ランウェイ
   - テーブル：詳細数字

3. **直接雇用部門PL月次推移** (グラフ)
   - 売上・利益の月次推移

4. **派遣部門PL月次推移** (グラフ)
   - 売上・利益の月次推移

### 事業指標タブ
1. **業種別支援人数月次推移** (グラフ + テーブル)
   - 業種ごとの支援人数の推移

2. **業種別紹介人数月次推移** (グラフ + テーブル)
   - 業種ごとの紹介人数の推移

3. **派遣重要変数月次推移** (グラフ + テーブル)
   - 派遣の重要指標の推移

### 昨対比タブ
1. **業種別支援人数昨対比** (グラフ + テーブル)
   - 昨年同月比での支援人数比較

2. **業種別紹介人数昨対比** (グラフ + テーブル)
   - 昨年同月比での紹介人数比較

3. **派遣人数昨対比** (グラフ + テーブル)
   - 昨年同月比での派遣人数比較

4. **派遣総時間昨対比** (グラフ + テーブル)
   - 昨年同月比での派遣総時間比較

### パイプラインタブ
1. **全体ファネル別金額** (テーブル)
   - 各ステージの金額集計

2. **02 解決策合意案件一覧** (テーブル)
   - 金額・人数を表示

3. **03 価格合意案件一覧** (テーブル)
   - 金額・人数を表示
