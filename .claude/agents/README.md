# .claude/agents/ — AIエージェント組織図

ここは NINAITE の「AI組織」の定義書置き場です。
CFO（あなた）を頂点に、**3つの部**が並び、各部に**部長（取りまとめ役）**がいます。

## 組織図

```
              あなた（CFO・3役の意思決定者）
     ┌──────────────┼──────────────┐
     ▼              ▼              ▼
 finance-lead    admin-lead    planning-lead   ← あなたが話す相手はこの3人だけ
 (ファイナンス部長) (管理部長)     (経営企画部長)
     │              │              │
  専門部下たち     専門部下たち     専門部下たち    ← 部長が呼び分け・統合する
```

## やり取りのモデル（重要）

- **あなたは「部長」とだけやり取りします。** 個別の専門部下を直接呼ぶ必要はありません。
- 部長は、依頼を受けたら「自分で対応する or 適切な専門部下に振る」を判断し、
  配下の成果を**統合してエグゼクティブサマリで**あなたに返します。
- どの部長に話すか＝案件の性質で選ぶ:

| 相談内容 | 話す相手 |
|---|---|
| 月次数字・予実・SaaS KPI・runway・IR定量化 | **finance-lead**（ファイナンス部長） |
| 監査・内部統制・規程・労務/法務・IPO準備 | **admin-lead**（管理部長） |
| 事業部KPI・業務プロセス改革・商談監視 | **planning-lead**（経営企画部長） |

## フォルダ構成

```
.claude/agents/
├── _LEAD_TEMPLATE.md      部長を作るときの雛形
├── _TEMPLATE.md           専門部下を作るときの雛形
├── finance/               ファイナンス部
│   └── finance-lead.md
├── admin/                 管理部
│   └── admin-lead.md
└── planning/              経営企画部
    └── planning-lead.md
```

## 作り方の順序（ウォーターフォール禁止）

骨格（3部長）は先に置いてありますが、**専門部下は1体ずつ反復して肉付け**します。
1番手はファイナンス部の「月次クローズ・予実差異 解説」担当です。

共通前提は [CLAUDE.md](../../CLAUDE.md) を参照。
